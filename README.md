🕊️👨‍💻 Learn Lingo Backend
This is the backend for the Learn Lingo web application, providing REST API endpoints for user authentication, teacher data, and session management.

The backend includes:

- User registration, login, logout, and session handling  
- Teachers collection with details: name, languages, levels, rating, reviews, price per hour, lessons done, avatar, lesson info, conditions, experience  
- Favorites handling per user (add/remove teachers)  
- Secure password hashing and token-based sessions  
- Error handling and input validation  

🧰 Tech Stack
Node.js | Express | TypeScript | MongoDB | Mongoose | Axios | bcrypt | http-errors | REST API

💻 Features / My Contribution
- Fully implemented backend with Node.js, Express, and MongoDB  
- Connected frontend (Next.js/TypeScript) to backend API  
- Implemented authentication, session management, and teacher CRUD  
- Optimized API for production deployment
